# Storage contracts and arms orders from full stores (0.39).
#
# Storage contract: when a store is 95% full and still growing, a private firm that makes the
# resource (a member of a corporation if there is one) offers to store the surplus: +20% of
# the store's maximum (modifier pe_store_<res>, country_resource_max_<res>_add = 100 x
# pe_sto_<s>_mult) for five years. Its fee: every month 5% of our net production of that
# resource, which the firm sells on its own account (its base value goes to its corporation's
# cash or to the investor pool). A warehouse of the firm (pe_building_corp_storage) stands on
# its planet while the contract runs. Six months before the end the firm offers to extend it
# by five years (if the store is still 85% full). One offer a year, a refused resource waits
# five years.
# Per resource (short code s): pe_sto_<s>_m months left, pe_sto_<s>_k the firm's corporation
# (0 = independent), pe_sto_<s>_cap the extra capacity, planet flag pe_stb_<s> the warehouse.
# Offer: pe_sto_r (1-6, order of R below), pe_sto_kn, pe_sto_capn, pe_sto_feen,
# event_target:pe_sto_planet; renewal: pe_sto_rr.
#
# Arms order: at most every ten years, when the alloy store is 90% full, our defence
# contractor (otherwise the richest industrial corporation) offers to build warships of our
# newest design from half our alloys at its own yards (ours stay free): delivered after a
# year (pe.327) at the capital, ours with normal upkeep and naval capacity. On top it charges
# half the alloys' amount in trade, which goes to its cash.
# Call depths: pe_store_offer, pe_arms_offer 3 (pe_corp_step); pe_store_month 1 (pe.100);
# pe_store_sign 1 (pe.324).

			limit = { check_variable = { which = pe_sto_net value > 0 } }
			set_variable = { which = pe_sto_fee value = pe_sto_net }

			if = { limit = { check_variable = { which = pe_sto_mi_k value = 1 } } if = { limit = { check_variable = { which = pe_c1_on value = 1 } } change_variable = { which = pe_c1_cash value = pe_sto_fee } set_variable = { which = pe_sto_paid value = 1 } } }
